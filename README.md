# Nischal V Pattedar — Data Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and a small amount of JavaScript. No build step or paid service is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Free hosting (recommended: GitHub Pages)
1. Create a public GitHub repository, for example `nischal-portfolio`.
2. Upload the contents of this folder (the `index.html`, `styles.css`, `script.js`, and `assets/` folder) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and open the URL GitHub Pages shows, usually `https://YOUR-USERNAME.github.io/nischal-portfolio/`.

GitHub Pages offers free static hosting for public repositories. You can also deploy the folder to Vercel or Netlify on their free tiers.
